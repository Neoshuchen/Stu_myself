## 事实、推理与风险

### 事实

- Django 测试发现并执行 99 项，结果 `OK`；其中 AI 专项 31 项，新用例覆盖 Base URL 的三种协议端点补全和完整地址幂等兼容。
- `manage.py check` 和模拟完整 HTTPS/HSTS 参数的 `check --deploy --fail-level WARNING` 均为 0 个问题。
- `makemigrations --check --dry-run` 返回 `No changes detected`；真实 MySQL 已应用至 `learning.0016`。
- 真实服务冒烟返回 `database_vendor=mysql`、AI Redis 读写删除均成功、`credential_storage_available=True`。
- `pip check` 无损坏依赖；`pnpm install --frozen-lockfile` 未改锁文件；生产依赖审计无已知漏洞；Vite 构建成功。
- Django 开发服务器启动冒烟确认自动重载信息只输出一次；development server 警告按设计保留，正式部署仍使用 Gunicorn/Nginx。
- WhiteNoise 仅在生产配置加载；开发和测试不再因尚未执行 `collectstatic` 输出空目录告警，生产静态文件链路保持不变。
- Playwright 使用其锁定版本的 Chromium 执行 4 项测试并全部通过；额外断言单个页面首次只发起一次会话恢复请求，以及剪贴板 PNG 进入 multipart 请求、附件可移除后重新添加、发送按钮没有被透明文件控件覆盖、Enter 发送且 Shift+Enter 仅换行。延迟模型响应时，提交内容会立即离开输入框并显示为用户消息，随后才出现助手响应。角色事实为普通用户 `is_staff=False`、管理员 `is_staff=True`；测试账号、刷新令牌及级联业务数据均按用户名精确清理。清理后数据库恢复原有用户和业务数据，且无孤立刷新令牌；用户在验收期间自行保存的账号级 AI 配置与会话不属于测试数据并予以保留。
- 浏览器回归曾暴露小队用例在页面异步加载完成前调用 `locator.count()` 的竞态，导致测试跳过创建操作而误报页面失败；用例现等待 `.team-page` 可见后再判断表单，当前完整回归为 4/4。后端同期请求无 HTTP 500、Traceback 或未处理异常。

- 本地启动后，后端存活和就绪接口、前端首页、`/login` 路由及前端 `/api` 代理均返回 HTTP 200；验证结束后服务已停止。
- 检查当前 15 个 Markdown 文件中的 16 个本地链接，没有失效链接；排除本地环境与生成物后没有超过 5 MB 的项目文件。

### 推理

后端测试覆盖权限、归属、状态流转和异常分支，真实 MySQL/Redis 与浏览器关键流程补充了 SQLite 测试无法证明的运行态链路，因此可以确认当前核心实现与本地环境一致。浏览器套件没有穷举证据上传、学习日全部验收、多用户协作挑战和每一种失败提示，仍不能推断所有控件都已端到端覆盖。

### 风险

- 第三方模型协议由模拟响应验证；真实供应商的账号权限、余额、模型可用性和策略差异仍可能导致调用失败。
- 腾讯云 SES/SMTP、正式域名、TLS、容器网络、备份恢复和外部告警依赖部署环境，本机结果不能代替生产演练。
- 前端仍缺组件单元测试；现有 E2E 已覆盖登录、报名、社区发布、管理员权限和 AI 配置入口，下一步只在真实缺陷或上线前扩充证据上传、学习日完成、跨用户协作及 AI 多轮附件。
- 本地 AI Fernet 主密钥不在 Git 中。迁移包含已有 AI 凭据的数据库时必须安全同步同一主密钥，否则密文无法解密。

## 工程结构判断

- 后端保持一个 Django app 作为模型和迁移边界，同时按 `accounts`、`study`、`collaboration`、`community`、`ai`、`administration`、`system` 分域，避免改表名和重复兼容层；当前结构与项目规模匹配。
- `learning/urls.py` 与 SimpleJWT 设置直接引用各领域 View/Serializer，不再经过无行为的根级转发模块；这减少了一套需要同步维护的公开出口，不引入兼容分支。
- 前端保持页面、通用组件、请求、鉴权和图片处理分离；没有为了单个 AI 功能引入新的状态框架或供应商 SDK。
- 依赖版本和 pnpm 锁文件已固定，CI 已覆盖主要自动化验证；Docker 构建上下文通过 `.dockerignore` 排除虚拟环境、上传文件、依赖和构建目录。
- `backend/learning/tests.py` 和 `frontend/src/styles.css` 体积较大，但当前没有发现由此触发的行为缺陷。仅为缩短文件而拆分会增加无价值改动，应在出现明确维护冲突时按领域渐进拆分。
- `.gitignore` 已排除环境文件、秘密、数据库、上传、缓存、日志、覆盖率、浏览器自动化状态、依赖和构建产物；`.gitattributes` 固定 Linux 脚本及配置文件换行规则。

# 课程内容质量与后续改进

> 核对日期：2026-09-04
> 文档性质：当前课程事实、仍有效的质量边界和后续优先级。历史审计过程与已经修复的旧统计不再保留。

## 当前基线

- 唯一版本化课程源是 `backend/data/system_roadmaps.v2.json`，`schema_version=2`、`content_version=8`。
- 目录包含 13 条系统路线、379 个连续学习日：一条 42 日采集/Web/Android 综合路线，十一条 30 日专项路线，以及一条 Git 7 日路线。
- 运行时权威来源是 MySQL；JSON 只由 `import_curated_roadmaps` 校验并幂等导入。管理员人工编辑过的学习日默认不会被再次导入覆盖。
- 当前导入和测试会校验路线分类、连续日编号、必填内容、公开资料地址及内部来源泄漏；缩短路线时若待删除学习日已人工编辑或已有进度、讨论、建议，事务会中止。学习页面的完成门禁仍要求全部检查项和至少一份证据。

## 已完成治理

- 课程正文已统一到内容版本 8，并保持原路线标识及已有学习进度关联。
- 11 条 60 日路线按原阶段合并相邻主题为 30 日，避免用重复的讲解、练习和验收人为拉长周期；原有主题仍保留在合并后的核心知识与连续任务中。
- 原 182 日路线收敛为 42 日，只保留授权采集、Web 定位与还原、Android 静态/动态/Native 分析，删除与路线名称不一致的平台化、AI 和求职扩张。
- 知识详情的摘要、用途、基础知识、运行机制和课程作用改为职责不同的文本；未命中的并列术语只生成一条主题导读，不再逐词复制通用模板。
- 内容版本 8 为已审核概念保留独立解释，未单独收录的并列术语每日最多合并成一条应用导读；机制、工具、易错点和练习步骤全部绑定当天任务与验收，不再沿整条路线复制同一模板。
- 修复了数据库中 `crawler/javascript/android/ios` 等紧凑轨道标识被当成未知路线的问题，示例、工具和资料现在由真实轨道类型统一选择。
- 把 `/`、`+` 视为术语内部字符，修复 `I/O`、`/status`、`/model`、`/login` 等被错误拆分的内容；概念匹配改为最长关键词优先，避免 `Java.use` 误命中普通 Java 基础说明。
- 已按 30 日实际节奏换算阶段前置条件，并合并生活路线中每个子任务都重复的验收后缀。
- 已核对并修正 Cline 当前 IDE/CLI 安装口径与 Node.js 要求、Copilot CLI 版本命令、Gemini Checkpointing/`/restore`/`/rewind` 差异、MD5 安全边界、Base64 非加密属性和 ReAct 审计记录边界。

- 对 379 天的标题、核心知识、任务、验收、知识详情、参考案例与资料映射做全量检查，并逐路线人工复核先修关系、每日负荷、工具时效性、授权和专业边界。
- V8 导入后再次直读 MySQL：13 条路线共 379 个学习日，全部 `content.version=8`；6 条报名、7 条学习进度、3 条学习证据的主键、关联、状态和附件路径未变。
- 每条路线中每日机制、易错点和练习步骤的唯一数均等于路线天数；各路线有 5～16 组日级参考资料组合，Git 7 天为 7 组，已消除整条路线复制同一详情模板的问题。
- 120 个去重参考链接以公开官方文档、标准组织、政府与专业机构为主；对 Python/Requests/Scrapy/Playwright、MDN/Chrome/Babel、Android/Apple/LLDB/Frida、Git、MCP/A2A 及各 Coding Agent 的易变事实重新核对。

- 已删除课程输出中的内部资料地址，学习者资料只允许公开来源。
- 知识卡具备概念、机制、常见错误、最小实验、参考代码、预期结果、练习与掌握标准等结构。
- 对采集和逆向主题明确限定本人资产、专用靶场或已授权样本，不把 `robots.txt`、可访问页面或技术可行为视作授权。
- 课程导入、管理员正文保护和强制覆盖路径已有自动化测试。

## 仍需解决的质量边界

1. **实验资产不完整**：仓库没有课程专用 APK、iOS App、本地 HTTP 靶场或 Babel 实验工程；当前只包含应用自身的前后端依赖清单。涉及真实目标的学习日必须由学习者提供合法环境，不能宣称开箱即复现。
2. **依赖仍分散在正文**：当前目录仍包含 Babel、pytest 等工具说明和占位路径。上线固定实验前，应为每条路线提供独立、锁定版本的实验依赖和预检命令。
3. **掌握度主要依赖自评与同伴证据**：间隔复习、证据、缺口和朋友验证已经形成闭环，但尚无覆盖所有代码型任务的客观自动判题。
4. **内容变更缺少版本差异和回滚**：`content_edited_at` 可以保护人工修改，却不能向在学用户展示版本差异，也没有课程级一键回滚。
5. **移动端结论需要真实设备复核**：Android/iOS 路线涉及系统版本、签名、设备状态和工具版本差异，不能仅凭静态课件保证每个实验成立。

## 不采用的扩充

- 不用新增更多长路线掩盖实验不可复现的问题。
- 不为一份路线再建第二套课程模型、导入状态机或发布流程。
- 不执行模型生成的代码，也不让 AI 结果绕过人工确认和管理员审核。
- 不使用登录积分、全站排行榜或打卡次数代表掌握程度。

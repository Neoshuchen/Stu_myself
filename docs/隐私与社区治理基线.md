# 隐私与社区治理基线

本文与站内 `/privacy`、`/community-guidelines` 页面保持同一基线；正式上线前仍应补充运营主体和有效联系渠道，并结合所在司法辖区进行法律复核。

## 收集与用途

系统处理账号名、邮箱、学习进度、复盘、知识缺口、学习证据、社区内容、举报和必要的安全日志。数据仅用于身份验证、学习功能、内容审核、安全防护和匿名化运营分析，不从帖子推断敏感偏好，不出售个人数据。

## 保存与用户权利

- 验证码只在 Redis 中短期保存，使用后立即失效。
- 学习者可以导出自己的 Markdown 或 JSON 学习记录，并可申请停用或删除账号。
- 删除账号时清理学习记录、附件和社区关系；因其他学习者仍在使用而保留的公开路线应去除作者身份关联。
- 生产备份按明确周期轮换；账号删除后的数据会在备份自然过期时消失，紧急恢复不得把已删除账号重新投入使用。
- 用户应能获得数据访问、更正、导出、删除和投诉联系渠道。

## AI 学习助手

AI 是用户主动开启并配置第三方模型接口的处理流程。每次请求可能向该接口发送：用户问题、当前会话最近 4/8/12 轮文字，以及本次上传的图片或已提取文件文字。新建全局会话不自动发送当前学习日、复盘、学习证据、缺口、其他用户内容、邮箱或用户名；旧版已绑定学习日的会话仍可能包含其最小课程参考。OpenAI Responses 请求显式使用 `store: false`，但第三方是否留存、用于风控或受账号设置影响仍以对应供应商当时的协议为准。

- 临时 API Key 只保留在当前页面内存和单次后端请求内存，不写 Cookie、浏览器持久存储、MySQL、Redis或审计日志。
- 用户主动保存时，配置名称、接口协议、规范化后的模型请求地址和模型名称作为非秘密配置与用户账号绑定并保存在 MySQL；界面可填写 Base URL 或完整端点。API Key 使用独立 Fernet 主密钥加密，接口只返回末四位。密钥与保存时的接口地址绑定，不能静默发送到另一个会话地址。
- 用户可长期保存多条模型服务并在全局助手中选择、修改或删除；配置保留到用户删除配置或账号。连接地址或密钥变化时需要重新验证，主密钥不与应用密钥共用。
- 文字对话、模型配置、Token 用量和附件文件名元数据保存在 MySQL，直到用户删除会话或账号；当前版本没有自动保留期限和批量导出。
- 上传处理期间，超过 Django 内存上传阈值的文件可能短暂进入操作系统临时目录；生产容器将 `/tmp` 放在 tmpfs，请求结束后清理。清洗后的图片及提取出的 PDF/文本/源码正文随后只在 Redis 中限时缓存，默认最长 1 小时，也可能因内存淘汰或重启更早消失；它们不写入 media、MySQL 或备份。文件名会作为消息元数据保留。
- 图片限制为 JPEG/PNG/WebP，并重编码、限制像素和移除 EXIF/GPS；PDF 只读取有限页数，不支持加密或无文字扫描件；文本按白名单和字符上限读取。用户仍不得上传密钥、个人隐私、未授权代码或第三方机密。
- 上传内容和旧会话中的课程片段都被当作不可信参考数据，不能覆盖系统约束；回答以纯文本显示，不执行脚本、代码、联网搜索或模型工具调用。
- AI 可能给出错误、过时或虚构内容，不代表课程验收、学习完成、专业意见或系统已执行验证。学习状态只能由用户原有的检查、证据和完成流程改变。

用户删除会话后，MySQL 文字记录会立即删除，系统同时尝试清理仍存在的 Redis 附件缓存；如果 Redis 当时不可用，缓存最多保留到原 TTL，且已不能再通过会话接口访问。供应商侧已接收数据的删除与保存规则需要用户依据其供应商账号和政策处理。正式上线前，界面还应提供运营主体、联系方式及适用供应商隐私政策链接。

## 社区与课程边界

- 禁止发布违法内容、骚扰、隐私数据、真实账号凭据、恶意程序和未经授权的采集或逆向目标。
- 采集与逆向实验仅限本人资产、专用靶场或获得明确授权的样本。
- 举报先进入人工审核；除明显紧急风险外，不因单次举报自动删除内容或封禁账号。
- 管理处置应记录理由、操作者和时间，并提供申诉与撤销渠道。
- 社区内容和课程共建的展示、署名、许可与删除规则应在发布前明确告知贡献者。

## 安全事件

发现账号、密钥或用户数据可能泄露时，应立即限制访问、保留脱敏审计证据、轮换相关凭据、评估受影响范围，并按适用法律和运营规则通知相关用户与主管方。日志和事故材料不得继续扩散验证码、令牌、密码或附件正文。
